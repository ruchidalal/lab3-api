Lab 3 API - Codebase Portal

Welcome to the Lab 3 Task Management API project. This page provides direct navigation and links to point to the code files and resources in this repository.

Project Code Navigation

  • GitHub Repository: ruchidalal/lab3-api - The online code repository on GitHub.
  • Frontend UI: public/index.html - The static single-page application for managing tasks.
  • Server Configuration: src/app.ts - The Express app setup including middleware and static routes.
  • Main Entrypoint: src/index.ts - The startup script for the server.
  • API Routes:
    • src/routes/tasks.ts - CRUD operations for tasks (GET, POST, PUT, DELETE).
    • src/routes/health.ts - Health check route.
  • Database Store: src/store/taskStore.ts - In-memory database store for tasks.
  • Middlewares:
    • src/middleware/errorHandler.ts - Global error and 404 handlers.
    • src/middleware/validate.ts - Request payload validation middleware.
    • src/middleware/requestLogger.ts - HTTP request logging middleware.
  • API Tests: tests/taskApi.test.ts - Jest integration tests for all REST endpoints.

How to Run

To run the application locally, use the following commands:

npm install
npm run dev

Once running, you can access the frontend UI at http://localhost:3000.
